# 🩺 ChestVision AI

Premium AI-powered Chest X-Ray Classification System built using TensorFlow, VGG16 Transfer Learning, OpenCV and Streamlit.

## Features

- COVID-19 Detection
- Viral Pneumonia Detection
- Normal Chest X-Ray Detection
- Premium Medical Dashboard UI
- Real-time AI Prediction
- Confidence Score Visualization
- Interactive Knowledge Base

## Technology Stack

- Python
- TensorFlow
- VGG16 Transfer Learning
- OpenCV
- NumPy
- Streamlit

## Classes

1. COVID-19
2. Normal
3. Viral Pneumonia

## Project Structure

```text
app.py
requirements.txt
README.md
```

## Model File

The trained model weights are automatically downloaded from Google Drive during deployment.

No manual upload of the `.h5` file is required.

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Streamlit Deployment

1. Create a GitHub repository.
2. Upload:
   - app.py
   - requirements.txt
   - README.md

3. Deploy using Streamlit Community Cloud.

4. Set:

```text
Main file path:
app.py
```
