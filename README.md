# 🩺 AI Medical Assistant - Chest X-Ray Detection

A premium deep learning web application for automatic Chest X-Ray classification using Transfer Learning with VGG16. The system can classify chest X-ray images into:

* COVID-19
* Normal
* Viral Pneumonia

Built with TensorFlow, Streamlit, OpenCV, and VGG16 Transfer Learning.

---

## 🚀 Features

* Premium Medical AI Dashboard
* Real-Time X-Ray Analysis
* Deep Learning Prediction Engine
* Confidence Score Visualization
* Interactive Probability Distribution
* Medical Knowledge Base
* Responsive Modern UI
* Automatic Model Download from Google Drive

---

## 🧠 AI Model

### Architecture

* VGG16 (ImageNet Pretrained)
* Transfer Learning
* Frozen Convolutional Layers
* Custom Classification Head

### Classes

| Class           | Description                |
| --------------- | -------------------------- |
| COVID-19        | Coronavirus Lung Infection |
| NORMAL          | Healthy Chest X-Ray        |
| Viral Pneumonia | Viral Lung Infection       |

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/covid19-chest-xray-detection.git
cd covid19-chest-xray-detection
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 📊 Model Performance

The model uses Transfer Learning with VGG16 and a custom classification head consisting of:

```python
Flatten()
Dense(256, activation="relu")
Dropout(0.5)
Dense(3, activation="softmax")
```
